---

## What This Does

This project syncs ICF Global chapter member records into GlueUp. A scheduled Make.com scenario pulls the active member list from the ICF Global SOAP API on demand (currently weekly). This toolset compares that data against the current GlueUp membership list, identifies new and changed records, and produces import-ready files for manual upload via the GlueUp Admin UI.

All sync and deduplication logic anchors on **ICF Global Member ID** — never on email address.

Key constraints this toolset handles:
- Members without a shared email address require a **shadow email** (proxy key) to satisfy GlueUp's unique email requirement
- GlueUp member records are immutable once written — updates require creating a new record and cancelling the old one
- GlueUp custom fields use property keys (not display names) in API payloads
- GlueUp authentication uses a custom HMAC-SHA256 scheme

## Prerequisites

- Python 3.8 or higher
- Install dependencies:

```bash
pip3 install -r requirements.txt --break-system-packages
```

- `glueup_token.json` in the working directory — generated by running `GetToken.py`
- `credentials.json` in the working directory — required for Google Drive upload (one-time setup; see [Google Drive Setup](#google-drive-setup))
- `ZipCodes_Areas_CCC.xlsx` in the working directory — required for Local Region lookup

> ⚠️ Neither `glueup_token.json` nor `credentials.json` should ever be committed to this repo. Both are listed in `.gitignore`.

## Setup

### 1. Copy environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in your chapter's GlueUp public and private keys and other org-specific values. See [Adapting for Your Chapter](#adapting-for-your-chapter) for the full list of values to replace.

### 2. Authenticate to GlueUp

```bash
python3 scripts/GetToken.py
```

This saves `glueup_token.json` to your working directory. Re-run if the token expires (~7 days) or the GlueUp password changes.

> If the GlueUp password changes, regenerate the MD5 hash first:
> - macOS: `md5 -s 'PASSWORD'`
> - Linux: `echo -n 'PASSWORD' | md5sum`

### 3. Google Drive Setup (one-time)

Before Drive upload will work, `credentials.json` must be present in the working directory:

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create or select a project and enable the Google Drive API
3. Create OAuth 2.0 credentials (Desktop app type)
4. Download as `credentials.json` into the working directory
5. The first run of `GlobalGlueUpSync.py` will open a browser for auth and cache `drive_token.json`

## Phase 1 Workflow

The ICF Global data pull is handled automatically by a scheduled Make.com scenario (currently weekly). When the scenario runs, it pulls the active member list from the ICF Global SOAP API and writes it to a dated CSV in the shared Google Drive Inbound folder, then sends a notification email to trigger the admin steps below. Alternatively, the GlobalGlueUpSync script can be run by running the gcloud scheduler for glueup-sync-weekly. That job may be scheduled to run after the Make scenario, if desired. The steps below are if a manual run is needed, on a local machine. 

| Step | Who | Action |
|---|---|---|
| 1 | Make | Get Active Members scenario runs on schedule and produces `activemembers_YYYYMMDD.csv` in Data-Transfer > Inbound. Sends notification email to glueupnotifiers@. |
| 2 | Admin | Confirm `glueup_token.json` is present and valid. If expired: `python3 GetToken.py`. |
| 3 | Admin | Run `python3 scripts/GlobalGlueUpSync.py` (auto-discovers most recent activemembers file), or `python3 scripts/GlobalGlueUpSync.py <filename.csv>`. Add `--no-drive` to skip Drive upload. |
| 4 | Admin | Review console summary. Check VALIDATION ERROR lines. Verify NEW / CHANGED / SAME counts are plausible. Review `comparison_report` for any unexpected CHANGED records. |
| 5 | Admin | Upload `contact_import_*.xlsx` via GlueUp Admin UI > **Contacts > Import**. Select **Has Titles** and **Overwrite**. |
| 6 | Admin | Upload `membership_import_*.xlsx` via GlueUp Admin UI > **Members > Import**. Select **ICF Chapter Member (Type ID 37600)** in step 1. Verify field mappings in step 3. Confirm import and activate. Activation triggers the Welcome system email. |
| 7 | Admin | Review GlueUp import results. Green = success. Red = error (usually duplicate email or missing required field). Investigate any red rows. |

### Output Files

Each run produces five timestamped output files:

| File | Description | Action Required |
|---|---|---|
| `contact_import_YYYYMMDD_HHMM.xlsx` | NEW and CHANGED members (33 columns) | Upload via GlueUp Admin UI > Contacts > Import |
| `membership_import_YYYYMMDD_HHMM.xlsx` | NEW active members + CHANGED memberships (34 columns) | Upload via GlueUp Admin UI > Members > Import |
| `comparison_report_YYYYMMDD_HHMM.xlsx` | Field-by-field diff: Summary, Detail, and Changed tabs | Review before importing |
| `duplicate_report_YYYYMMDD_HHMM.xlsx` | Members with >1 active GlueUp membership for same ICF Member ID | Cancel flagged records in GlueUp Admin UI |
| `run_log_YYYYMMDD_HHMM.txt` | Full console output: counts, validation errors, skip warnings | Review for anomalies |

## Script Reference

| Script | Command | Purpose |
|---|---|---|
| `GlobalGlueUpSync.py` | `python3 scripts/GlobalGlueUpSync.py` | Full run: auto-discover most recent activemembers CSV, compare, produce 5 output files, upload to Drive |
| `GlobalGlueUpSync.py` | `python3 scripts/GlobalGlueUpSync.py <file.csv>` | Full run with specified input file |
| `GlobalGlueUpSync.py` | `python3 scripts/GlobalGlueUpSync.py --no-drive` | Full run, skip Drive upload |
| `GlobalGlueUpSync.py` | `python3 scripts/GlobalGlueUpSync.py --dry-run` | Look up all members and print summary; do not write output files |
| `GetToken.py` | `python3 scripts/GetToken.py` | Authenticate to GlueUp. Run if token is missing or expired. |
| `ExGetRecord.py` | `python3 scripts/ExGetRecord.py --email <email>` | Look up a member by email, name, or ICF Member ID |
| `GetFieldCodes.py` | `python3 scripts/GetFieldCodes.py --print` | Verify custom fields and option codes are current |
| `GetMultiMembers.py` | `python3 scripts/GetMultiMembers.py --csv` | Find contacts with duplicate memberships |
| `DeleteMultiMembers.py` | `python3 scripts/DeleteMultiMembers.py` | Dry run duplicate removal. Add `--confirm` to execute. |
| `ContactAudit.py` | `python3 scripts/ContactAudit.py --in export.xlsx` | Audit contacts for duplicates, shadow emails, unlinked members |

## Adapting for Your Chapter

The following values are chapter-specific and must be updated before use. Search the scripts for these placeholders or hardcoded values and replace with your chapter's equivalents.

| What | Where to find it | Used in |
|---|---|---|
| GlueUp public key | GlueUp Admin > API Settings | `GetToken.py`, `.env` |
| GlueUp private key | GlueUp Admin > API Settings | `GetToken.py`, `.env` |
| GlueUp Org ID | GlueUp Admin > Organization Settings | `GlobalGlueUpSync.py`, `.env` |
| GlueUp Membership Type ID | GlueUp Admin > Membership Types | `GlobalGlueUpSync.py`, `.env` |
| GlueUp account email | Your chapter's GlueUp admin email | `GetToken.py` |
| GlueUp password MD5 hash | Generate from your GlueUp password | `GetToken.py` |
| Google Drive Inbound folder ID | Google Drive URL when folder is open | `GlobalGlueUpSync.py`, `.env` |
| Google Drive Sync Output folder ID | Google Drive URL when folder is open | `GlobalGlueUpSync.py`, `.env` |
| GlueUp contact import template | Export from your GlueUp Admin UI | `GlobalGlueUpSync.py` |
| GlueUp membership import template | Export from your GlueUp Admin UI | `GlobalGlueUpSync.py` |
| ZipCodes_Areas_CCC.xlsx | Generate from your chapter's zip/region data | `GlobalGlueUpSync.py` |
| Shadow email domain | Your chapter's member email domain | `GlobalGlueUpSync.py` |

> **Important:** After updating credentials, run `python3 scripts/GetFieldCodes.py --print` to verify that your chapter's GlueUp custom field keys match what the scripts expect. Field keys vary between GlueUp organizations and the scripts must be updated to match yours.
