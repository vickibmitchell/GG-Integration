## What This Does

This project syncs ICF Global chapter member records into GlueUp. Each month, ICF Global publishes a member export. This toolset compares that export against the current GlueUp membership list, identifies new and changed records, and produces import-ready files for manual upload via the GlueUp Admin UI.

All sync and deduplication logic anchors on **ICF Global Member ID** — never on email address.

## Prerequisites

- Python 3.8 or higher
- Install dependencies:

```bash
pip3 install -r requirements.txt --break-system-packages
```

- `token.json` in the working directory — generated by running `GetToken.py`
- `credentials.json` in the working directory — required for Google Drive upload (one-time setup; see [Google Drive Setup](#google-drive-setup))

> ⚠️ Neither `token.json` nor `credentials.json` should ever be committed to this repo. Both are listed in `.gitignore`.

---

## Setup

### 1. Copy environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in the GlueUp public and private keys. The scripts currently read these values from the source directly — this file is a reference for future refactoring.

### 2. Authenticate to GlueUp

```bash
python3 scripts/GetToken.py
```

This saves `token.json` to your working directory. Re-run if the token expires or the GlueUp password changes.

> If the GlueUp password changes, regenerate the MD5 hash first:
> - macOS: `md5 -s 'PASSWORD'`
> - Linux: `echo -n 'PASSWORD' | md5sum`

### 3. Google Drive Setup (one-time)

Before Drive upload will work, `credentials.json` must be present in the working directory:

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create or select a project and enable the Google Drive API
3. Create OAuth 2.0 credentials (Desktop app type)
4. Download as `credentials.json` into the working directory
5. The first run of `ICFGlueUpSync.py` will open a browser for auth and cache `drive_token.json`

## Phase 0 Workflow

| Step | Who | Action |
|---|---|---|
| 1 | Admin | Log in to ICF Global portal and download the chapter member export as `.xlsx`. Close the file before proceeding. |
| 2 | Admin | Place the `.xlsx` file in the **Inbound** Google Drive folder (Shared Drive: Data Transfer > Inbound). |
| 3 | Admin | Run `python3 scripts/ICFGlueUpSync.py <file.xlsx>` |
| 4 | Admin | Review `comparison_report_*.xlsx` Summary tab — note NEW / CHANGED / SAME counts. |
| 5 | Admin | Review `dropped_members_*.xlsx` — cancel dropped memberships in GlueUp Admin UI. |
| 6 | Admin | Upload `glueup_import_*.xlsx` via GlueUp Admin UI: **Members > Import**. |
| 7 | Admin | Re-run the script with the same file — import file should be empty (0 records). |
| 8 | Admin | Review `duplicate_members_*.xlsx` and resolve any duplicate records. |

## Script Reference

| Script | Command | Purpose |
|---|---|---|
| `ICFGlueUpSync.py` | `python3 scripts/ICFGlueUpSync.py <file.xlsx>` | Full run: compare, produce 4 output files, upload to Drive |
| `ICFGlueUpSync.py` | `python3 scripts/ICFGlueUpSync.py <file.xlsx> --no-drive` | Full run, skip Drive upload |
| `ICFGlueUpSync.py` | `python3 scripts/ICFGlueUpSync.py <file.xlsx> --import-mode all` | Include ALL records in import file |
| `ICFGlueUpSync.py` | `python3 scripts/ICFGlueUpSync.py <file.xlsx> --import-mode new` | Include only NEW records |
| `GetToken.py` | `python3 scripts/GetToken.py` | Authenticate to GlueUp. Run if token is missing or expired. |
| `ExGetRecord.py` | `python3 scripts/ExGetRecord.py --email <email>` | Look up a member by email, name, or ICF Member ID |
| `GetFieldCodes.py` | `python3 scripts/GetFieldCodes.py --print` | Verify custom fields and option codes are current |
| `GetMultiMembers.py` | `python3 scripts/GetMultiMembers.py --csv` | Find contacts with duplicate memberships |
| `DeleteMultiMembers.py` | `python3 scripts/DeleteMultiMembers.py` | Dry run duplicate removal. Add `--confirm` to execute. |
| `ContactAudit.py` | `python3 scripts/ContactAudit.py --in export.xlsx` | Audit contacts for duplicates, shadow emails, unlinked members |
